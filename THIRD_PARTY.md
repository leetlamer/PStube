`src/ps4_platform.cpp` adapt the official OpenOrbis graphics helper. Controller
initialization follows the official input sample. Resource ownership, checked
errors, timed flip waits, and shutdown handling are additions for this project.

- [OpenOrbis PS4 Toolchain v0.5.4](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/tree/v0.5.4), GPL-3.0; see `LICENSE`.
- Inspected samples: `samples/hello_world/hello_world/main.cpp`, `samples/graphics/graphics/main.cpp`, `samples/_common/graphics.cpp`, `samples/input/input/controller.cpp`.
- SDK archive: `toolchain-llvm-18.tar.gz`, SHA-256 `3c7cd5bb593ca74fa1c13fd59f3938dc0fc07985167f7275063019e63abe4526`.

- [LibOrbisPkg](https://github.com/maxton/LibOrbisPkg), LGPL-3.0; the SDK includes release 0.2.231. Its SFO and package commands are documented in `vendor/OpenOrbis/PS4Toolchain/bin/macos/README.md`.
- Runtime placeholders `sce_module/libc.prx` and `sce_module/libSceFios2.prx` are copied unchanged from the SDK `src/modules/`. Their source functions return zero; these are OpenOrbis-built placeholders, not proprietary Sony runtime libraries. The official SDK build script copies them into every application sample.
